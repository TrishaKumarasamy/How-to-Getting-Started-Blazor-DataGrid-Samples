# Blazor DataGrid Samples

A comprehensive collection of sample applications demonstrating how to build and configure Blazor applications with DataGrid components. This repository provides practical examples of both **WebAssembly** and **Server-side** Blazor architectures, along with advanced styling techniques using CSS Isolation.

## Overview

This project contains three complete Blazor applications:

- **BlazorApp**: A client-side (WebAssembly) Blazor application with DataGrid integration
- **BlazorServerApp**: A server-side Blazor application with DataGrid and services
- **CSS_Isolation**: A modern Blazor application showcasing CSS Isolation for component-scoped styling

Perfect for developers looking to understand how to set up components in different Blazor hosting models and learn best practices for styling and component integration.

## Features

- **Client-Side Blazor (WebAssembly)**: Standalone apps running in the browser with full .NET runtime
- **Server-Side Blazor**: Real-time communication with the server over WebSocket connections
- **CSS Isolation**: Component-scoped styling using `.razor.css` files for clean, maintainable styles
- **DataGrid Integration**: Production-ready data grid components with sorting, filtering, and pagination
- **Modern .NET 9.0**: Built with the latest .NET framework for performance and features

- [Visual Studio Code](https://code.visualstudio.com/)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/How-to-Getting-Started-Blazor-DataGrid-Samples.git
cd How-to-Getting-Started-Blazor-DataGrid-Samples
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.
